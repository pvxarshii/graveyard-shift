# Graveyard Shift - Overview

A 2D survival roguelite inspired by *Vampire Survivors*.

## Project Overview

Graveyard Shift is a survival roguelite where players fight increasingly dangerous waves of enemies, collect experience, and grow stronger through upgrades.

## Project Details

- **Genre:** 2D Survival Roguelite
- **Engine:** Godot
- **Language:** C#
- **Art Style:** Pixel Art — Tiny Swords by Pixel Frog
- **Status:** In Development

## Gameplay

The core gameplay revolves around surviving enemy waves, improving the player's abilities, and lasting as long as possible.

1. **Survive** — Move around the arena and avoid incoming enemies.
2. **Fight** — Automatically target and attack nearby enemies.
3. **Collect** — Gather experience from defeated enemies.
4. **Upgrade** — Level up and choose upgrades to improve your character.
5. **Progress** — Face increasing difficulty and survive as long as possible.
